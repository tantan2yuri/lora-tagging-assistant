LoRA Tagging Assistant

LoRA Tagging Assistant is a free Windows application designed to assist with tagging, captioning, and dataset preparation for LoRA training.

LoRA Tagging Assistant は、LoRA学習用データセットの タグ付け・キャプション作成・整理を支援する無料のWindowsアプリケーションです。

About

All features of LoRA Tagging Assistant are available free of charge. There are no supporter-only features or paid feature restrictions.

LoRA Tagging Assistant のすべての機能は無料で利用できます。 支援者限定機能や、支援の有無による機能制限はありません。

Support Development

If you find LoRA Tagging Assistant useful, you may leave a voluntary tip through Ko-fi to support continued development, testing, maintenance, and improvements.

If you do not leave a tip, you can continue to use all features of LoRA Tagging Assistant without any restrictions.

LoRA Tagging Assistant が役に立ったと感じていただけた場合は、 Ko-fiを通じて任意のTipで今後の開発を応援していただけます。

Tipは、今後の開発・テスト・保守・機能改善などに活用させていただきます。 Tipの有無によって利用できる機能に違いはありません。

Important / ご案内

Tips are entirely voluntary and do not constitute payment for additional software features, digital content, or supporter-exclusive benefits.

Tipは完全に任意です。 Tipによって追加機能、デジタルコンテンツ、 支援者限定特典などが提供されるものではありません。
